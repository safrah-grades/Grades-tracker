# سجل متابعة درجات الطلاب
صفحة رصد الدرجات والحضور وتقارير أولياء الأمور لمدرسة سافرة الابتدائية الإعدادية للبنين.

البيانات لا تُحفظ هنا؛ تُحفظ في مستودع خاص يُربط من «الإعدادات ← الربط مع GitHub».

إعداد وتصميم: أ. خالد الحمري

## متابعة الخطط الفردية وخطط الفئات – بالعربية أرتقي
الصفحة: `arteqi.html` — متابعة الخطط الفردية وخطط الفئات والمتابعة الصفية والحضور والتقارير وطباعة الأنشطة.
بياناتها تُحفظ في المستودع الخاص نفسه (ملف `arteqi.json`)، وتُربط من «الإعدادات ← الربط مع GitHub».
